Chapter 3 • String Manipulation

Deciphering the Transmission

"Quack! The duck elders reversed the message and added erratic spaces to hide the secret password!"

Task

Define a function decode_signal(message) that takes a string message.

Your function must:

1. Remove any leading and trailing whitespace from the string.

2. Convert the text completely to lowercase.

3. Return the reversed string.

Examples

decode_signal("TIbkCAUQ") # Returns: "quackbit" decode_signal(" NOHTYP ") # Returns: "python" decode_signal(" ") # Returns: ""

Guidelines

• In Python, you can strip spaces with .strip() and convert to lowercase with .lower().

• To reverse a string s, you can use slice notation s[::-1].
