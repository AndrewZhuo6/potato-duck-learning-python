The Duck's Supply Bag

Potato Duck steps past the castle gate into the great storehouse. Before advancing, Potato Duck needs to count their rations!

Chapter 2 • Lists & Loops

Ration Inventory Check

"Quack! A long voyage requires plenty of potatoes. Let's write a function to tally our supplies!"

Task

Define a function count_potatoes(bag, item_name) that takes:

1. bag: a list of strings representing items in the duck's backpack.

2. item_name: a string representing the target item to count.

Your function should return the total number of times item_name appears in bag.

Examples

count_potatoes(["potato", "apple", "potato"], "potato") # Returns: 2 count_potatoes(["carrot", "bread"], "potato") # Returns: 0 count_potatoes([], "potato") # Returns: 0

Guidelines

• You can iterate through the list with a for loop, or use Python's built-in bag.count(item_name).

• Return an integer count.
