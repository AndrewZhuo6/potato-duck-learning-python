Calorie Calculator

"Quack! Calculate the total calories in Potato Duck's snack stash so we know if we have enough stamina to jump!"

Task

Define a function calculate_energy(food_dict) where food_dict is a Python dictionary with food names as keys and integer calories as values.

Your function should calculate and return the sum of all calorie values. If the dictionary is empty, return 0.

Examples

calculate_energy({"potato": 150, "corn": 100, "berries": 50}) # Returns: 300 calculate_energy({}) # Returns: 0 calculate_energy({"super_potato": 500}) # Returns: 500

Guidelines

• You can retrieve all values in a dictionary using food_dict.values().

• Use Python's built-in sum() function or a for loop to aggregate.
