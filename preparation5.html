Chapter 5 • Capstone Challenge

The Master Seal

"Quack! The vault door monitors both team power and the royal cryptographic cipher key!"

Task

Define a function unlock_master_vault(team_powers, master_key) where:

1. team_powers is a list of integers representing the power of each duck member.

2. master_key is a secret string.

The vault opens (returns True) if and only if:

• The sum of all numbers in team_powers is at least 100 (>= 100), AND

• The master_key string starts with "QUACK".

Otherwise, return False.

Examples

unlock_master_vault([30, 40, 35], "QUACK_MASTER_2026") # Returns: True unlock_master_vault([10, 20, 30], "QUACK_PASS") # Returns: False (sum=60 < 100) unlock_master_vault([50, 60], "WRONG_KEY") # Returns: False (key prefix mismatch)

Guidelines

• You can use Python's sum(team_powers) and string method master_key.startswith("QUACK").

• Return a boolean: True or False.
